## I. Qadamma-qadam yechim

**Qadam 1 — `app/handlers/admin.py`, `get_role`/`is_hr` funksiyalaridan
KEYIN (`:41` dan so'ng) middleware klassini qo'shish.** Tartib muhim:
klass `is_hr`/`get_role` ni ishlatgani uchun ular yuqorida turishi shart,
ulash qatorlari esa klassdan keyin (Qadam 2) — aks holda `NameError`.

```python
from aiogram import BaseMiddleware
from aiogram.types import CallbackQuery

class AdminGuardMiddleware(BaseMiddleware):
    """Admin router'ning har event'ida ruxsatni tekshiradi (default-deny).

    is_hr bo'lmasa handler UMUMAN chaqirilmaydi — yangi handler qo'shilganda
    ham himoya avtomatik. Rolni data['role'] ga qo'yadi.
    S2 (tahlil/S2.md, R3): markazlashgan avторизация qatlami.
    """
    async def __call__(self, handler, event, data):
        user = data.get("event_from_user")
        role = await get_role(user.id) if user else None
        # Chegara — is_hr, "rol bormi" EMAS: project_admin ham kirmasligi kerak
        if not is_hr(role):
            if isinstance(event, CallbackQuery):
                await event.answer("❌ Ruxsat yo'q.", show_alert=True)
            # message bo'lsa — jim (oddiy foydalanuvchi admin buyrug'ini bilmasin)
            return
        data["role"] = role
        return await handler(event, data)
```

⚠️ `is_hr(role)` `role=None` bilan ham xavfsiz: `None in ("hr_admin",
"super_admin")` → `False` (`admin.py:40-41`), ya'ni alohida `if not role`
tekshiruvi shart emas.

**Qadam 2 — ulash. Bu qatorlar `AdminGuardMiddleware` klassi TA'RIFIDAN
KEYIN turishi shart** (Python literal tartibda o'qiydi). Ya'ni `admin.py:30`
dagi `router = Router()` joyida qoladi, ulash esa klassdan so'ng yoziladi:

```python
# ── admin.py:30 (o'zgarishsiz)
router = Router()

# ── get_role / is_hr / AdminGuardMiddleware ta'riflaridan KEYIN:
router.message.middleware(AdminGuardMiddleware())
router.callback_query.middleware(AdminGuardMiddleware())
```

**Qadam 3 — regressiyani tekshirish:** middleware `data["role"]` beradi;
mavjud handlerlar hali `role = await get_role(...)` chaqiradi — bu takror,
lekin zararsiz. Ularni o'zgartirish SHART EMAS (orqaga mos). Ixtiyoriy
tozalash keyingi bandga qoldiriladi.

**Qadam 4 — nozik holat:** ba'zi handlerlar `role` ni parametr sifatida
kutmasligi mumkin — middleware `data["role"]` ni qo'shadi, lekin handler uni
signaturasida olmasa aiogram uni e'tiborsiz qoldiradi (aiogram faqat handler
so'ragan parametrlarni uzatadi). Ya'ni buzilmaydi.

**Qadam 5 — super_admin-only tasdiqlash:** admin boshqaruvi handlerlari
(`add_admin` va h.k.) allaqachon `SUPER_ADMIN_ID` tekshiradi — o'zgarishsiz
qoladi. Middleware ularga "role bor" darvozasini qo'shadi, super_admin qatlami
ustида ishlaydi. Buzilish yo'q.

## J. Xavf, migratsiya, rollback

  uchun rollback xavfsiz.
- **Deploy tartibi:** oddiy `./deploy.sh` — maxsus qadam yo'q.
- **Zaxira:** kod o'zgarishi, DB'ga tegmaydi — deploy.sh baribir bot.db
